naegong-uploader 개인정보처리방침

시행일: 2026년 11월 18일

naegong-uploader는 개발자가 자신의 YouTube 채널에 영상을 올리고 관리하기 위해 만든 개인용 도구입니다. 일반 사용자에게 제공되는 서비스가 아니며, 채널 소유자 본인 외에는 이 앱으로 로그인하지 않습니다.

1. 이용하는 정보

YouTube Data API를 통해 채널 소유자 본인의 YouTube 계정에서 다음 작업에 필요한 정보만 사용합니다: 영상 업로드, 제목·설명·태그·공개 상태 수정, 썸네일 등록, 재생목록 관리, 채널 확인.

2. 보관과 공유

로그인 토큰은 채널 소유자의 개인 저장 공간에만 보관합니다. 어떤 정보도 제3자에게 판매·공유하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.

3. Google API 정책

이 앱이 Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 앱은 YouTube API 서비스를 사용하며, 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

4. 접근 권한 철회

언제든지 Google 계정의 서드 파티 연결에서 이 앱의 접근 권한을 삭제할 수 있습니다.

naegong-uploader Privacy Policy

Effective: November 18, 2026
